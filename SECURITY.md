# Security Policy

## Reporting a Vulnerability

To report a security vulnerability within Harmonix or one of its official packages, please report it privately using the [GitHub Security Advisories page](https://github.com/harmonix-js/harmonix/security/advisories/new) (see [documentation](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)).

To ensure your Harmonix-based bots remain secure:

- Always keep dependencies up to date (`pnpm update` or `npm update`).
- Regularly review your Discord bot's permissions and environment variables.
- Never expose any tokens or other secrets in your code or version control.
